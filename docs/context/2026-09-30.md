## 1. Executive Summary & Current State

The **Akari Watanabe AI Companion** is a low-latency multimodal conversational agent featuring:
- **3D VRM Anime Avatar**: Rendered at 60 FPS in WebGL/Three.js with audio-reactive blendshape viseme lip-syncing.
- **Multimodal Intelligence**: Unified support for OpenAI (GPT-4o, GPT-4o Mini), Mistral AI (Ministral 8B, Mistral Small), Free.ai, and OpenRouter.
- **Tool Calling Subsystem**: Native multi-round function execution supporting real-time web search, math calculation, time/date conversions, and dynamic tool discovery.
- **Summary Buffer Memory Compaction**: Prevents context drift and unbounded token consumption by automatically compacting older dialogue turns into dense background memory when conversation length exceeds threshold.
- **Tavily AI Search & Crawl**: Multi-tier web search combining authenticated Tavily SDK, keyless Tavily search, and local DuckDuckGo fallback.

## 2. Web Search & AI Crawler Subsystem (`server/src/tools/builtins.py`)

Adhering to the official **Tavily Agent Setup Specification** (`tavily.com/agent-setup/SKILL.md`):

### 2.1 Multi-Tier Search & Direct Website Crawl Execution
1. **Direct Website Crawling (`Tavily Extract API`)**:
   - Automatically detects explicit `url` parameter or extracts valid URLs (`https?://...`) and domain patterns (`example.com`) from queries.
   - When a user asks about a specific website (e.g. `https://hermesworkspace.com/` or `hermesworkspace.com site overview and purpose`), routes directly to `_crawl_target_url` using Tavily's `/extract` endpoint.
   - Strips raw markdown boilerplate and extracts the true, live homepage/domain content directly, avoiding third-party blog misattributions.
   - Falls back gracefully to direct HTTP GET crawling if Tavily Extract is unavailable.
2. **Tier 1: Authenticated Tavily AI Search** (`tavily-python` SDK):
   - Triggered for general web search queries when `TAVILY_API_KEY` is present in `server/.env`.
   - Executes `TavilyClient(api_key).search(query, search_depth="basic", include_answer=True, max_results=3)`.
   - Returns pre-synthesized AI answers (`ai_summary`) and verified sources (`title`, `url`, `snippet`).
3. **Tier 2: Keyless Tavily REST API**:
   - Conforms to Tavily Agent Setup Path E:
     Sends HTTP POST to `https://api.tavily.com/search` (or `/extract`) with header `X-Tavily-Access-Mode: keyless`.
   - Provides out-of-the-box AI web search, website extraction, and answer synthesis without requiring initial API key configuration.
4. **Tier 3: Local DuckDuckGo Search Fallback** (`ddgs` / `duckduckgo_search`):
   - Local fallback if network rate limits or offline constraints block Tavily requests.

### 2.2 Dual-Layer Brevity & Compact Response Enforcement
- **Payload Condensation**: Crawled content is strictly stripped of navigation links and capped at ~500 characters.
- **In-Payload Directive**: Tool return payload explicitly instructs: `"instruction_for_akari": "State what this website is in 1 or 2 compact sentences. Do not mention unrelated blogs or unnecessary details, and do not write long paragraphs."`
- **System Prompt Rules**: Mandatory conciseness instructions enforce 1–2 sentence dialogue across both voice and chat modes.

## 3. Dynamic Tool Discovery & Lean Prompting

### 3.1 Unbloated System Prompt Strategy
Rather than enumerating every function signature and parameter in `SYSTEM_PROMPT_AKARI_ASSISTANT`, only the primary tools are highlighted in the prompt:
- `web_search`: Live web search, news, current events, and online facts.
- `get_current_time`: Local and international time lookups.
- `calculate`: Exact arithmetic, percentages, and math expressions.

To access all other tools (time difference, day of week, timezone metadata, system status), the model dynamically queries `get_available_tools`, which is registered and enabled in `tool_registry`.

### 3.2 Conversational Pacing & Length Rules
In `server/src/prompts/system_prompt_akari.py`:
- Spoken responses maintain natural, expressive dialogue pacing suitable for real-time voice calls.
- Contains an explicit rule advising against unnecessary rambling:
  `"Do not give overly long responses. Keep your dialogue natural and reasonably concise, only providing longer responses when needed or asked."`
- Artificial token clipping (`max_tokens=300`) was removed from Mistral chat calls to avoid mid-sentence cutoffs when longer answers are genuinely warranted.

## 4. Conversation History Compactor (`server/src/llm/compactor.py`)

### 4.1 Architecture (Summary Buffer Memory Pattern)
- **Threshold Gating**:
  - `COMPACTION_THRESHOLD_MESSAGES = 16` (~8 complete dialogue turns).
  - `COMPACTION_THRESHOLD_CHARS = 8000` (~2,000 tokens).
  - Normal chat turns (turns 1–7) completely bypass compaction with 0 overhead.
- **Recency Retention**:
  - `KEEP_RECENT_MESSAGES = 6` (~3 recent turns) are preserved verbatim.
  - Ensures immediate pronoun references, short-term conversational context, and recent tool outputs remain accurate.
- **Cumulative Background Memory**:
  - Compiles older turns into a structured transcript and asks the active LLM to generate an objective, information-dense summary.
  - Prepends a memory block to the active conversation:
    `[UserMessage("[Context from earlier conversation:\n<summary>\n(Background memory)]")]`
    `[AssistantMessage("[Understood, I remember everything we talked about.]")]`
- **Fail-Safe Mechanism**:
  - If the summarization request fails or times out, it gracefully falls back to sliding-window truncation.
